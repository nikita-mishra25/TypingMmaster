# ⌨️ Typing Master Project

Typing Master is a simple web-based typing practice application built using **HTML, CSS, and JavaScript**.  
It helps users improve typing speed and accuracy by calculating WPM, time taken, and errors.

---

## 🚀 Features
- Random typing text (100 / 200 / 500 words)
- Typing timer starts on first key press
- Live countdown timer
- Words Per Minute (WPM) calculation
- Accuracy calculation
- Correct and wrong word count
- Keypress sound effect
- Simple and beginner-friendly UI

---

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
